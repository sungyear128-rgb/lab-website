# 메인 배너 뇌 이미지 수정팩

이번 수정은 Home의 오른쪽 뇌 배너만 변경합니다.

## 수정 내용
- 기존 선형 SVG 뇌 그림 제거
- 새로 생성한 오리지널 뇌/신경망 이미지를 실제 웹 자산으로 적용
- PNG 원본을 WebP로 최적화해 로딩 용량 감소
- 카드 비율을 1:1로 안정적으로 유지
- 기존 네이비/코발트 계열 디자인, 둥근 모서리, 그림자 유지
- 데스크톱/태블릿/모바일 반응형 대응
- 마우스를 올리면 아주 약한 확대 효과 적용
- CMS 데이터, app.js, 다른 페이지는 수정하지 않음

## GitHub에 올릴 파일
저장소 최상단 기준으로 아래 3개를 덮어쓰면 됩니다.

index.html
assets/css/style.css
assets/images/hero-brain.webp

`.pages.yml`, `data/`, `assets/js/app.js`는 수정하지 마세요.

## 이미지 사용
이번 뇌 이미지는 이 사이트를 위해 새로 생성한 AI 이미지이며,
기존 스톡 이미지를 가져와 삽입한 것이 아닙니다.
