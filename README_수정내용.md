# 요청사항 3개 수정본

## 1. People → Members
- 상단 메뉴의 People을 Members로 변경
- Footer의 People도 Members로 변경
- `people.html` 파일명은 링크 호환성을 위해 유지
- Members 페이지의 `Lab Members` 제목은 그대로 유지

## 2. Resources 제거
- 모든 상단 메뉴에서 Resources 제거
- 모든 Footer에서 Resources 제거
- 예전 `resources.html` 주소로 직접 들어가면 Home으로 자동 이동
- Pages CMS의 자료실 데이터는 삭제하지 않음

## 3. Contact 지도
- 기존 캡처 이미지 지도를 외부 Google Maps 임베드 지도로 변경
- 작은 지도 영역 클릭 → 큰 팝업 지도
- 큰 지도 안에서 Google Maps 자체 + / − 확대·축소 가능
- 마우스/터치 드래그로 지도 이동 가능
- 배경 클릭, X 버튼, ESC로 닫기

지도 기준 주소:
강원특별자치도 춘천시 한림대학길 1, 한림대학교

## 업로드
ZIP을 풀어 안의 파일/폴더를 GitHub 저장소 최상단에 업로드하여 덮어쓰세요.
`.pages.yml`과 `data/`는 건드리지 않습니다.
